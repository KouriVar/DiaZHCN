# 术语规范（定版）

本文件记录已定版的界面术语。新增词条一律照此执行；既有词条不因本文件而改名
（`translations/zh-Hans.strings` 是唯一译文来源，改动须单独评审）。

## 1. 产品功能名

| 英文原文 | 定版译法 | 说明 |
|---|---|---|
| `companion panel` | 伴随面板 | Dia 的伴随面板功能，不使用「伴侣 / 配套 / 助手」 |
| `Formats` / `Format` | 格式 | 不使用「输出格式」；`Format the response as…` 句式按动词「排版」处理 |
| `Workstream Tasks` | 工作流任务 | 与 `Tasks`（任务）、`Communication Tasks`（沟通任务）并列区分 |
| `usage credits` | 用量额度 | 不使用「积分 / 点数」；`usage credit balance` 为「用量额度余额」 |
| `auto-reload` | 自动充值 | 语境是用量额度的自动补充，不使用「自动重载」 |
| `Daily Brief` | 每日简报 | 与 `Morning Brief`（晨间简报）严格区分，两者不可混用 |

## 2. 与既有译法冲突时的取值

下列英文在历史版本中已存在 fork 译法，与本项目早期参考资料不同。定版一律取
**既有译法**，不得改动现有键，新增键也向此靠拢：

| 英文原文 | 定版译法（采用） | 不采用的译法 |
|---|---|---|
| `Back` | 后退 | 返回 |
| `Thinking` | 思考中 | 正在思考 |
| `Search Google` | 使用 Google 搜索 | 搜索 Google |
| `Creating artifact` | 正在创建内容 | 正在创建作品 |

## 3. 其他既有约定

- 省略号跟随英文原文形态：原文 `...` 译 `...`，原文 `…` 译 `…`。
- 占位符（`%@`、`%1$@`、`%d`）位置与数量必须与原文完全一致。
- 保存 / 分享 / 启用 / 停用 / 扩展程序 / 个人资料 / 新建聊天 / 常规 /
  隐私和安全 / 全屏幕 / 智能拷贝 沿用既有词表。
- 用户内容（书签、历史、窗口名、网页标题、聊天内容）与技能实际执行的 prompt
  一律不翻译。

## 4. 变更流程

新增或修订术语需同时更新本文件与 `translations/zh-Hans.strings`，并在
`CHANGELOG.md` 记录；改既有键须单独提交并说明影响面。
